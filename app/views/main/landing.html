Dúvidas Frequentes

Perguntas Frequentes

Tudo o que precisa de saber sobre a segurança, funcionamento e sincronização da sua loja.

Preciso de conhecimento técnico para conectar as integrações?

Não. A integração é feita através dos identificadores das suas contas (como o Shop ID da Shopee, User ID do Mercado Livre ou Seller ID do AliExpress) diretamente no ecrã de configurações. O Stoppa Core gere todo o barramento técnico de dados sem que precise de programar.

Como se comporta o sistema em caso de vendas simultâneas?

O Stoppa Core opera com controlo concorrente a nível de base de dados (WAL Mode). Quando uma venda é confirmada em qualquer canal, o saldo físico da variação é abatido e propagado em milissegundos para todos os outros marketplaces conectados, prevenindo que produtos sem stock físico continuem disponíveis.

A minha equipa terá acesso a dados financeiros ou lucros?

Apenas se autorizar. O sistema conta com controlo de acessos baseado em cargos (RBAC). Operadores têm acesso apenas à conferência de stock e catálogo, enquanto relatórios financeiros, lucros e configurações sensíveis ficam isolados exclusivamente para administradores e proprietários.

O sistema suporta produtos com grades de tamanhos e cores?

Sim. O catálogo do Stoppa Core foi desenvolvido para tratar variações de forma independente: cada variante conta com SKU próprio, código de barras EAN, fotografia dedicada, custo de reposição e stock mínimo de segurança individual.

É necessário cadastrar cartão de crédito para começar?

Não solicitamos dados de pagamento no registo. Cria a sua conta, cadastra os seus primeiros produtos e inicia a gestão imediatamente sem qualquer compromisso financeiro.
